Workflow Engine

Automate the boring stuff

Define workflows in JSON. Run them from the dashboard. No code, no CI pipeline needed.

deploy-api.json 
{
  "name": "Deploy API",
  "runElevated": true,
  "tags": ["deploy", "api"],
  "steps": [
    {
      "type": "downloadFile",
      "source": "github",
      "url": "...release artifact...",
      "destination": "%appdata%\\MyApp"
    },
    {
      "type": "extractArchive",
      "source": "%appdata%\\MyApp\\app.zip",
      "destination": "%appdata%\\MyApp"
    },
    {
      "type": "restartWindowsService",
      "serviceName": "MyApiService"
    }
  ]
}

From JSON to done

Chain any combination of steps. Add a tag, hit Run. DevelopmentHub handles UAC prompts, variable substitution, and streams logs in real time.

  • Shell scripts & executables
  • Authenticated GitHub / Azure DevOps downloads
  • ZIP extraction + JSON patching
  • Windows service restarts
  • UAC elevation — no manual runas
  • Sub-workflow composition
  • Static & built-in path variables
  • Real-time execution log stream

Plugin System

Build anything on top

Add widgets and full pages without forking the host. Ship as a .dll + bundle.js.

First-class extensibility

Plugins run in isolated AssemblyLoadContexts on the backend and receive a typed SDK on the frontend — React, TanStack Query, Zustand, React Router, and a pre-built themed UI component set.

  • Declare widgets & routes in manifest.json
  • Backend: implement IPlugin, add REST endpoints
  • Frontend: call window.__dhSdk to register
  • No host code changes ever needed
  • Per-plugin settings pages — built in
  • Load error surfaced in Settings UI
Read the plugin guide →
bundle.js 
// Runs in the host WebView2 context
const { plugin, components } = window.__dhSdk;

// Register a sidebar page
plugin.registerPage({
  id:        'my-plugin',
  label:     'My Plugin',
  icon:      'fa-solid fa-star',
  component: MyPage,
});

// Register a dashboard widget
plugin.registerWidget({
  id:        'my-widget',
  label:     'My Widget',
  minW: 2, minH: 2,
  component: MyWidget,
});
